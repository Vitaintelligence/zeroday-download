# ZeroDay Client Downloads

## Install (Windows) — one line, copy-paste into PowerShell:
```powershell
powershell -ExecutionPolicy Bypass -Command "irm https://github.com/Vitaintelligence/zeroday-download/releases/latest/download/install.ps1 | iex"
```

## Manual install
1. Download [ZeroDay-Client-v4.3.zip](https://github.com/Vitaintelligence/zeroday-download/releases/latest/download/ZeroDay-Client-v4.3.zip) and extract.
2. Double-click `START.bat`.

Python 3.10+ and AutoHotkey are installed automatically if missing (or get Python from https://www.python.org/downloads/ and re-run).
