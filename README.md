# ZeroDay Client Downloads

Latest client package: [ZeroDay-Client-v4.3.zip](https://github.com/Vitaintelligence/zeroday-download/releases/latest/download/ZeroDay-Client-v4.3.zip)

## Install (Windows)
1. Download and extract the zip.
2. Double-click `START.bat`.
3. Python 3.10+ and AutoHotkey are installed automatically if missing (or get Python from https://www.python.org/downloads/ and re-run).

One-line install (PowerShell):
```powershell
irm https://github.com/Vitaintelligence/zeroday-download/releases/latest/download/install.ps1 -OutFile install.ps1; .\install.ps1
```
